Propósito de la reunión

Finalizar los requisitos del proceso de compras para el nuevo sistema.

Puntos clave

  - Proceso de importación definido: Las importaciones de fruta de Naturprime desde Naturifarms requieren trazabilidad completa, incluyendo números de pedimento y todos los costos asociados, que deben fluir hasta la factura de venta final.
  - OC de importación automatizadas: Para reducir la captura manual, Naturprime usará una API para crear automáticamente Órdenes de Compra (POs) en Odoo a partir de las órdenes de venta generadas en el sistema SAP de Naturifarms.
  - Mermas de plantas cargadas a viveros: La merma de plantas (merma) se rastreará y se cargará al vivero responsable específico, no al proveedor principal NVG.
  - Requisiciones controladas por presupuesto: El sistema aplicará un flujo de aprobación de múltiples niveles para las requisiciones, con presupuestos vinculados a cuentas analíticas y límites de gasto por empleado.

Temas

Compras intercompañía

  - La función nativa multi-compañía de Odoo gestionará los servicios entre las tres entidades: Naturberry, Naturagui y Naturprime.
  - Naturberry: Compra fruta y materiales a NVG.
  - Naturagui: Compra servicios de frío (frío) y fitosanitarios a Naturberry.
  - Naturprime: Compra fruta importada a Naturifarms.

Proceso de importación y automatización

  - Proceso: Naturprime compra fruta importada a Naturifarms.
  - Trazabilidad: El sistema debe rastrear el número de pedimento, fecha de entrada y puerto de aduana.
      - Justificación: Permitir trazabilidad completa para rechazos y asignar todos los costos asociados (p. ej., impuestos, honorarios del agente) a la importación específica.
  - Automatización: Una API creará automáticamente OCs en el Odoo de Naturprime a partir de las órdenes de venta generadas en el SAP de Naturifarms.
      - Justificación: Eliminar la captura manual y agilizar el proceso.

Inventario y facturación de servicios

  - Inventario de plantas: Las compras de plantas para Naturberry se registrarán pero se enviarán directamente al productor, omitiendo el almacén de Naturberry.
      - Método: Se utilizará un flujo de trabajo de "triangulación" modificado para asegurar trazabilidad sin movimiento físico de inventario.
  - Inventario de fruta importada:
      - Propiedad: La fruta pertenece a Naturprime, que gestiona sus ventas.
      - Visibilidad de Naturagui: Naturagui necesita facturar a Naturprime por servicios (p. ej., etiquetado, reempaque).
      - Solución: Naturagui recibirá un reporte de cajas recibidas/enviadas, no acceso completo al inventario.
      - Justificación: Proporcionar a Naturagui los datos necesarios para facturar sin exponer detalles sensibles de la fruta (p. ej., variedad, rancho).

Flujo de requisición y aprobación

  - Se requiere un flujo de aprobación de múltiples niveles para las requisiciones, especialmente para consumibles.
  - Flujo del proceso:
    1.  Solicitud: El empleado crea una requisición.
    2.  Aprobación: El gerente inmediato aprueba o rechaza.
    3.  Creación de OC: Las solicitudes aprobadas pasan al equipo de compras (Tania) para la creación de la OC.
  - Aplicación de presupuesto:
      - Las requisiciones se validarán contra presupuestos vinculados a cuentas analíticas y límites de gasto por empleado.
      - Las solicitudes que excedan los límites requerirán una autorización de nivel superior.
  - Portal de proveedores: Los proveedores usarán un portal para subir facturas y evidencias, reemplazando el sistema actual de Jodeform.
