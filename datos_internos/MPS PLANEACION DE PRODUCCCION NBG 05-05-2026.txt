Propósito de la reunión

Definir los requisitos de planificación de producción y trazabilidad en Odoo.

Puntos clave

  - Necesidad central: Odoo debe automatizar el flujo de trabajo manual en Excel de Edder para la planificación de producción, pronósticos y seguimiento del desempeño.
  - Trazabilidad crítica: El sistema debe vincular la fruta a su vivero de origen (vivero) para analizar el desempeño por variedad (por ejemplo, ciclo de plantación a cosecha).
  - Destino de mercado: La fruta se identifica como Nacional o Exportación solo en la venta, no en la recepción, para mantener flexibilidad de inventario ante cambios de pedidos de último minuto.
  - Inventario de plantas: El sistema debe gestionar el inventario de plantas con lógica FIFO, rastreando la antigüedad de los lotes para evitar el uso de stock antiguo.

Temas

Planificación de producción y pronósticos

  - Objetivo: Automatizar el proceso manual en Excel de Edder para la planificación de producción y los pronósticos.
  - Pronóstico de siembra: La grower list de Edder será el plan de siembra del sistema, detallando:
      - Variedad
      - Vivero (vivero)
      - Calendario de entregas semanales
  - Pronóstico de cosecha: Edder cargará un pronóstico semanal (cajas/hectárea/variedad) para las próximas 6 semanas.
      - Este pronóstico requiere actualizaciones semanales para reflejar las condiciones reales.
  - Seguimiento del desempeño: Odoo debe comparar la producción real vs. el pronóstico.
      - Alertas: Notificar a Edder cuando la entrega real de un productor se desvíe significativamente del pronóstico (por ejemplo, 600 cajas vs. 1,300 pronosticadas).
      - Tablero: Generar un tablero gráfico y sencillo similar al reporte actual de Power BI de Edder, mostrando resúmenes semanales por productor, variedad y empaque.

Trazabilidad: Planta a fruta

  - Objetivo: Vincular la fruta cosechada con su vivero de origen para analizar el desempeño por variedad.
  - Desafío: La fruta de un productor puede provenir de múltiples viveros, lo que dificulta la trazabilidad directa lote a lote.
  - Solución: Los productores identificarán el vivero en la entrega de fruta.
      - Método: El personal de recepción ingresará manualmente el ID del vivero (por ejemplo, una letra) desde la etiqueta del productor.
      - Justificación: Este método es factible porque los productores suelen segmentar sus campos por vivero.
      - Acción: Víctor coordinará con el equipo de Gloria para implementar este nuevo requisito de etiquetado con los productores.

Gestión de inventario de plantas

  - Requisito: El sistema debe rastrear el tipo de planta (a raíz desnuda vs. en plug) desde el pedido inicial al vivero.
      - Justificación: Estos datos son críticos para la facturación de Rafa y para analizar diferencias de desempeño entre tipos de planta.
  - Lógica FIFO: El sistema debe aplicar Primero en entrar, primero en salir (FIFO) para plantas a raíz desnuda en almacenamiento en frío.
      - Justificación: Esto evita que se pase por alto el stock antiguo y asegura una rotación adecuada del inventario.

Lógica de destino de mercado

  - Proceso: La fruta se recibe como un producto genérico (por ejemplo, "Fresa 1 libra").
      - Justificación: Esto mantiene la flexibilidad del inventario ante cambios de pedidos de último minuto.
  - Identificación: El destino de mercado (Nacional/Exportación) se asigna solo en la venta.
      - Mecanismo: El sistema identifica el mercado según el cliente en la orden de venta.
      - Salida: Odoo debe generar manifiestos de envío para cada embarque Nacional y de Exportación.

Datos históricos e integración climática

  - Datos históricos: Se cargarán datos pasados sobre entregas de plantas y cosechas de fruta para construir una base para futuros pronósticos.
  - Datos climáticos: Integrar datos climáticos semanales (temperatura, humedad, lluvia) en el análisis de desempeño.
      - Justificación: Para comprender cómo el clima afecta el desempeño por variedad.
      - Método: Definir cuadrantes geográficos específicos (por ejemplo, Chavinda, Jacona) para la recolección de datos, ya que los climas locales varían significativamente.

Próximos pasos

  - Edder: Refinar el archivo Excel grower list y compartirlo para el viernes.
  - Víctor:
      - Definir con Edder los cuadrantes geográficos para datos climáticos.
      - Mapear los productores a sus respectivos cuadrantes.
      - Encontrar y compartir la fuente de datos climáticos históricos.
      - Coordinar con el equipo de Gloria para implementar el requisito de etiquetado con ID de vivero con los productores.
  - Robert: Programar una reunión extendida para el viernes para revisar el archivo final de Edder e incluir a Gloria para discutir requisitos de inocuidad.
  - Inflexyon (Emiliano, Alex): Revisar los requisitos y analizar cómo implementarlos mejor en Odoo.
