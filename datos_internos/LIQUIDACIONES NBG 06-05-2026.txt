Propósito de la reunión

Definir y mapear en Odoo los procesos de liquidación de productores y de Naturprime.

Puntos clave

  - Dos procesos de liquidación distintos: El proyecto implementará dos flujos de liquidación separados:
      - Naturberry (Productor): Calcula el precio al productor deduciendo costos fijos (p. ej., cámara fría, regalías) a partir de las ventas en EE. UU.
      - Naturprime (Ventas nacionales): Calcula el precio de retorno para Naturberry deduciendo costos variables (p. ej., fletes, comisiones) de los ingresos por ventas nacionales.
  - El objetivo es el flujo de datos automatizado: El objetivo principal es reemplazar flujos manuales en Excel por un flujo de datos automatizado. Esto requiere:
      - Una interfaz con el sistema estadounidense "Acknowledge" para extraer datos de ventas en bruto para los cálculos de Naturberry.
      - Funcionalidad intercompany para vincular las órdenes de venta de Naturprime con las órdenes de compra de Naturberry.
  - La gestión de productores es la base: Es fundamental un módulo sólido de gestión de productores. Debe almacenar:
      - Contratos: Odoo generará contratos a partir de una plantilla, usando datos ingresados una sola vez.
      - Retenciones dinámicas: Un rol dedicado (el de José Manuel) gestionará los porcentajes de retención semanales, que pueden modificarse desde una base contractual, con un registro de auditoría de todos los cambios.
      - Reglas fiscales: El sistema debe manejar reglas complejas, como el seguimiento del único cambio de razón social de facturación de un productor a mitad de temporada y la gestión de retenciones fiscales RECICO condicionales.
  - Validación automática de facturas: Para asegurar exactitud, Odoo validará las facturas de los productores contra sus propias órdenes de compra leyendo el archivo XML. Las discrepancias activarán automáticamente una notificación de rechazo al productor.

Temas

Liquidación de productores (Naturberry)

  - Descripción general del proceso: Un proceso semanal en dos pasos determina los pagos a productores.
    1.  Cálculo de precio: Usa datos de ventas en EE. UU. (de "Acknowledge") para calcular un único precio de retorno mixto por cada presentación de fruta, cubriendo tanto exportación como mercado nacional.
    2.  Pago al productor: Aplica este precio a las entregas semanales de cada productor y luego deduce las retenciones para determinar el pago neto final.
  - Automatización de la fuente de datos:
      - Problema: El proceso actual depende de un archivo de Excel de EE. UU. manipulado manualmente.
      - Solución: Se construirá una interfaz para extraer directamente los datos de ventas en bruto desde la base de datos de Acknowledge. Esto automatiza el primer paso y elimina el riesgo de fórmulas rotas en Excel.
  - Módulo de gestión de productores:
      - Generación de contratos: Odoo generará "Contratos de Comercialización" a partir de una plantilla, utilizando datos clave ingresados en el registro del productor.
      - Historial por temporada: El sistema debe almacenar un historial completo de los contratos, retenciones y precios de cada productor para cada temporada.
      - Complejidad fiscal:
          - Entidad de facturación: Rastrear el único cambio a mitad de temporada de la entidad de facturación (RFC) de un productor, un derecho que debe especificarse en su contrato.
          - Impuesto RECICO: Permitir la aplicación condicional de la retención de impuesto RECICO del 1.25%, ya que algunos productores están exentos.
      - Financiamiento: Diferenciar entre "préstamos" con interés (gestionados mediante tablas de amortización) y "financiamiento" sin interés (gestionado mediante retenciones).
  - Validación automática de facturas:
      - Proceso: Odoo comparará automáticamente el XML de la factura enviada por el productor contra la orden de compra del sistema.
      - Validación: El sistema verificará coincidencias en RFC, importes, cantidades y régimen fiscal.
      - Acción: Si hay discrepancias, la factura se rechaza y un correo automático notifica al productor para corregir y reenviar.

Liquidación de ventas nacionales (Naturprime)

  - Descripción general del proceso: Naturprime actúa como distribuidor nacional de Naturberry, calculando el precio de retorno para Naturberry al deducir todos los costos variables de los ingresos por ventas nacionales.
  - Automatización intercompany:
      - Flujo de trabajo: Una orden de venta de Naturprime disparará automáticamente una orden de compra a Naturberry.
      - Inventario: La cámara fría enviará directamente al cliente final, con una transferencia intercompany moviendo el inventario de los libros de Naturberry a los de Naturprime para su facturación.
  - Cálculo de costos y precios:
      - Órdenes de venta: Capturarán todos los costos variables (p. ej., flete, termógrafos, certificados) y descuentos específicos del cliente.
      - Costos fijos: Las tarifas estándar (p. ej., 8% de comisión de Naturprime, 20% de margen) se extraerán del registro maestro del cliente.
      - Rechazos: La fruta rechazada vendida en consignación se vinculará con la venta original. Una nota de cargo reconciliará la diferencia final de precio con Naturberry.
  - Facturación automatizada:
      - Objetivo: Generar y timbrar automáticamente la factura de venta al cliente final al confirmar el embarque desde la cámara fría.
      - Requisito: Requiere datos completos y precisos del cliente (RFC, uso de CFDI, condiciones de pago) en Odoo.
