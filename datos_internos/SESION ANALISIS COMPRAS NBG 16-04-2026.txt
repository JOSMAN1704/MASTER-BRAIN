VIEW RECORDING: 
Propósito de la reunión

Definir y mapear el proceso de compras para el nuevo sistema ERP.

Puntos clave

  - Control presupuestario: El sistema requiere un módulo de presupuesto restrictivo (por departamento y empleado) que bloquee las solicitudes por encima del presupuesto, con una anulación flexible para el Gerente de Compras.
  - Logística de plantas: El "almacén virtual" para plantas es el proceso más complejo. Requiere una transacción única y en tiempo real donde los asesores de campo registren tanto la entrega entrante desde el vivero (anotando calidad/merma) como la entrega saliente inmediata al productor.
  - La trazabilidad es primordial: Todos los costos de un envío (flete, servicios, reempaque) deben vincularse a un único número de seguimiento. Esto habilita la visibilidad total de costos y permite cambios de destino (p. ej., Walmart → mercado) sin perder el historial de costos original.
  - Rediseño de procesos: El equipo pausará la definición de flujos de compras de forma aislada. En su lugar, primero mapearán procesos de extremo a extremo (p. ej., ciclo de vida de la planta, importación/exportación) para identificar correctamente dónde se necesitan órdenes de compra (PO), órdenes de venta (SO) y transferencias.

Temas

Proceso general de compras

  - Flujo de solicitud: Solicitud del empleado (en Odoo) → Aprobación del gerente → Revisión de Compras (para cotizaciones, presupuesto) → Creación de PO.
  - Control presupuestario:
      - El sistema debe hacer cumplir presupuestos por departamento y empleado.
      - Las solicitudes que excedan el presupuesto deben ser bloqueadas, requiriendo una anulación por parte del Gerente de Compras.
      - Esta anulación debe ser una autorización, no una modificación del presupuesto, para preservar el registro de presupuesto original para su seguimiento.
  - Factura y pago:
      - No se puede pagar una PO sin una factura cargada y comprobante de entrega.
      - Decisión: Usar la política de "factura basada en la cantidad ordenada". Esto simplifica el procesamiento inicial; cualquier discrepancia (p. ej., faltantes) se gestionará con una nota de crédito por separado.

Logística de plantas: El "almacén virtual"

  - Desafío: Las plantas nunca se almacenan físicamente. Se entregan directamente del vivero a los productores, creando un "almacén virtual" que requiere un flujo de trabajo único en el sistema.
  - Flujo de trabajo propuesto:
    1.  PO a NVG: Naturberry emite una PO a NVG para plantas.
    2.  Transacción en tiempo real: Un asesor de campo usa una app móvil para registrar una única transacción simultánea en el sitio de entrega:
          - Recepción entrante: Registra la entrega desde el vivero, incluyendo controles de calidad y merma.
          - Entrega saliente: Registra la transferencia al productor, vinculándola al lote entrante.
    3.  Creación de SO: El sistema genera automáticamente una solicitud de Orden de Venta (SO) para el productor basada en los datos de la entrega.
  - Justificación: Este flujo de trabajo asegura precisión del inventario en tiempo real y proporciona una pista de auditoría clara tanto para el vivero (proveedor) como para el productor (cliente).

Gestión de fletes

  - Complejidad: El negocio usa múltiples tipos de flete con distintos pagadores y flujos de trabajo.
      - Nacional: Naturprime paga la entrega final desde el cooler de Naturagui hasta el cliente.
      - Exportación: Naturberry paga el transporte desde los coolers regionales hasta el punto de consolidación de Naturagui.
      - Planta: Naturberry paga el transporte de plantas de cepellón a los productores.
  - Requisito crítico: El sistema debe permitir a usuarios autorizados cambiar el destino final de un envío en el mismo pedido. Esto preserva el historial de costos original y evita perder la trazabilidad.

Servicios intercompañía

  - Servicios de Naturagui: Naturagui presta servicios (enfriamiento, reempaque) a Naturprime y Naturberry. Se gestionarán mediante POs intercompañía.
  - Reempaque de Naturberry: El servicio de reempaque de Naturberry para importaciones también se gestionará con una PO intercompañía.
  - Servicios de NVG: Los pagos por servicios de NVG (p. ej., honorarios de Alfredo) seguirán el proceso estándar de PO.

Próximos pasos

      - Programar una sesión dedicada para definir el proceso complejo de gestión de fletes.
  - Todos: Asistir a la reunión de seguimiento sobre el proceso de "Almacenes" mañana a la 1:00 PM.
