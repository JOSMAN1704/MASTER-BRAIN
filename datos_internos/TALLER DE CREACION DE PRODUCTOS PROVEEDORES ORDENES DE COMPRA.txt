Odoo & NBG  - Taller de creación de productos-proveedores-gestión de órdenes de compra - May 13
VIEW RECORDING: 
Propósito de la reunión

Revisar las funciones de Odoo para creación de productos, gestión de proveedores y órdenes de compra.

Puntos clave

  - Odoo v19 admitirá tres empresas: Naturberry, Naturagui y Naturprime, con catálogos compartidos para mayor eficiencia.
  - La configuración del producto es la base de todas las operaciones: Define el seguimiento de inventario (por lote para costos reales), las políticas de venta/compra y los datos críticos para documentos de exportación.
  - La plantilla estándar de Odoo es insuficiente; se requieren campos personalizados para necesidades específicas como pesos neto/bruto en facturas de exportación y seguimiento de origen para cumplimiento IMEX.
  - Plan de acción: Formar tres grupos de trabajo (Ventas, Materiales, Servicios) para definir requisitos de datos personalizados, creando un catálogo de productos sólido que evite problemas de datos del pasado.

Temas

Descripción general de la implementación de Odoo v19

  - Versión: Odoo v19 (versión estable actual).
  - Empresas: Naturberry, Naturagui, Naturprime.
  - Catálogos compartidos: Productos, clientes y proveedores se compartirán entre empresas para agilizar operaciones.
  - Objetivo: Entender la creación manual de productos, la base de toda la gestión de compras e inventarios.

Creación y configuración de productos

  - Tipos de producto:
      - Almacenable: Bienes tangibles (plantas, clamshells) que se rastrean en inventario.
      - Consumible: Artículos no rastreados (material de oficina); su valor de compra va directamente a una cuenta de gastos.
      - Servicio: Artículos intangibles (renta, internet).
      - Combo: Un conjunto de productos (p. ej., un "paquete" de materiales para una venta).
  - Campos clave de configuración:
      - Indicadores de Venta/Compra: Habilitar/deshabilitar un producto para venta o compra.
      - Seguimiento de inventario:
          - Por cantidad: Conteo simple.
          - Por lote: Rastrea lotes específicos, permitiendo el seguimiento de costo real por lote (p. ej., Lote A @ $5, Lote B @ $5.50). Esto es crítico para una contabilidad de costos precisa.
      - Política de ventas: Facturar según "Cantidad Entregada" para coincidir con los envíos reales, no con el pedido inicial.
      - Política de compras: Facturar según "Cantidad Recibida" para pagar solo por bienes aceptados físicamente.
      - Categorías: Agrupar productos (p. ej., "Plantas", "Cepellón") para aplicar contabilidad y métodos de costeo predeterminados (p. ej., FIFO).
      - Información de proveedores: Vincular productos a proveedores específicos, incluyendo su precio y tiempo de entrega.

Requisitos de personalización y plan de acción

  - Problema: La plantilla estándar de productos de Odoo carece de campos críticos para las operaciones específicas de la empresa.
  - Brechas identificadas:
      - Datos de exportación: Se necesitan campos separados para Peso Neto y Peso Bruto en facturas de exportación.
      - Seguimiento de origen: Se requiere un campo dedicado para distinguir el origen del producto (p. ej., México vs. EE. UU.) para cumplimiento y reportes IMEX.
      - Lista de materiales (BOM): Se necesita una BOM para definir los componentes de un producto final vendible (p. ej., un pallet de fresas = fruta + caja + clamshell + pallet).
  - Solución: Crear plantillas personalizadas definiendo todos los campos requeridos desde el inicio.
      - Grupo de trabajo 1 (Ventas): Definir requisitos para todos los productos de fruta vendibles (p. ej., fresas, arándanos).
      - Grupo de trabajo 2 (Materiales): Definir requisitos para todos los materiales comprados (p. ej., cajas, clamshells, plantas).
      - Grupo de trabajo 3 (Servicios): Definir requisitos para todos los servicios y artículos no inventariables (p. ej., renta, intereses).

Próximos pasos

  - Robert:
      - Organizar las tres reuniones de grupos de trabajo para definir requisitos de datos personalizados de productos.
      - Confirmar la disponibilidad de Emiliano para unirse a las reuniones.
  - Todos los participantes:
      - Preparar una lista de campos personalizados requeridos para sus respectivas categorías de productos.
      - Usar la plantilla estándar de Odoo como base, agregando columnas personalizadas en un color distintivo para facilitar su identificación.
